# Prompt Injection and Social Engineering Attack Vectors
This repository contains research and documentation accompanying my Master's thesis in Enterprise & IT Security.

# Overview
This project investigates prompt injection vulnerabilities through the lens of social engineering attack vectors in Large Language Models (LLMs). It explores how threat actors exploit AI systems and evaluates the structural gaps between technical controls and administrative frameworks.

# Key Contents
* Threat Taxonomy: A comprehensive taxonomy synthesizing academic literature and established frameworks to classify prompt injection vectors by attacker intent, payloads, and model deployment methods.

* Incident Analysis: Case studies analyzing real-world security incidents (2022–2024) to evaluate how attacks bypassed enterprise safeguards and how organizations adapted their security measures.

* Framework Mapping: Comparative analysis bridging human-centric administrative controls (NIST SP 800-53) with technical AI security frameworks to identify LLM defense gaps.
